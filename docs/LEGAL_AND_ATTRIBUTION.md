# Legal, licensing and attribution checklist

**Working choice:** MIT for this project's original source and documentation. The maintainer must verify the intended copyright holder and third-party usage before public release.

## Reuse of external projects

- Do not mirror whole MCP servers into this repo merely for convenience.
- Dependencies remain under upstream licenses and maintainers. Refer to them using exact URLs, pinned tags and integration instructions.
- If files are copied, preserve original license and copyright notices; document modifications and distribution rights.
- Source code license != asset license. Synthetic examples must be original, public domain, or specifically licensed for redistribution.
- Check transitive packages and binary distributables separately.

## Respect attribution and truthfulness

- Describe actual maintainer roles accurately, including substantial external contributors.
- No requirement to market the project as "AI-made" by default; do not falsely claim manual authorship, conceal required disclosure, alter timestamps or forge contribution evidence.
- Each upstream integration is unendorsed unless written approval exists.

## Public release checks

- [ ] Confirm copyright owner name in LICENSE.
- [ ] Check current OSI-approved license compatibility.
- [ ] Resolve third-party SPDX entries and packaged notices.
- [ ] Review editor trademarks, logos and redistribution rights.
- [ ] Confirm no proprietary game assets, secret keys or private project excerpts.
- [ ] Confirm version claims against observed tests and public releases.

Not legal advice; use professional counsel for contested IP questions.
