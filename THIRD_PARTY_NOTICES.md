## Before copying upstream code

1. Identify exact file, release, SHA, copyright and licenses.
2. Confirm transitive dependencies, generated assets, bundled examples and optional assets are distributable.
3. Preserve original copyright/license notices and required attribution.
4. Record modifications with links to upstream code where required.
5. Prefer sending fixes upstream rather than maintaining unmanaged copy-paste forks.

No affiliation or endorsement by any upstream project is implied.
